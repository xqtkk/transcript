# 📝 YouTube Transcript Extractor

Простой и легковесный веб-инструмент для извлечения субтитров из видео на YouTube. Проект состоит из Python-сервера и минималистичного HTML/JS интерфейса, что позволяет обходить браузерные ограничения (CORS) и получать текст в виде удобного, читаемого абзаца без лишних переносов строк.

## ✨ Особенности

* **Извлечение субтитров по ссылке:** Поддержка видео с русскими и английскими субтитрами.
* **Форматирование текста:** Автоматическая склейка коротких фраз в связный текст без обрывов.
* **Независимая архитектура:** Раздельный фронтенд (статичный HTML) и бэкенд (Flask).
* **Готовность к облаку:** Настроен для бесплатного деплоя на сервисах вроде Render (включен Gunicorn).

## 🛠 Технологии

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Python 3, Flask, `flask-cors`, `youtube-transcript-api`, `gunicorn`

## 🚀 Как запустить локально

**1. Клонирование и настройка бэкенда**
Убедитесь, что у вас установлен Python. Склонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/ВАШ_НИК/youtube-transcript.git
cd youtube-transcript
pip install -r requirements.txt

```

**2. Запуск локального сервера**

```bash
python server.py

```

Сервер запустится на `[http://127.0.0.1:5000](http://127.0.0.1:5000)`.

**3. Запуск интерфейса**
Просто откройте файл `index.html` в любом современном браузере. Введите ссылку на видео YouTube в поле и нажмите кнопку загрузки.
